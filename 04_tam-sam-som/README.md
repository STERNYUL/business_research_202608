# 04 - TAM-SAM-SOM 과 Market Segment Map

시장 규모를 세 겹(전체 → 유효 → 획득가능)으로 좁혀 잡고, 세그먼트 맵으로 "누가 실제 고객인가"를 분해하는 프레임워크입니다.

| _(예정)_ 학습노트 | TAM-SAM-SOM 정의, Top-down/Bottom-up 산정법, Segment Map 작성법 | ⬜ |

## 이 프레임워크의 핵심 질문

| 층위 | 묻는 것 | 흔한 실수 |
|---|---|---|
| **TAM** (Total Addressable Market) | 이 문제 전체의 크기는? | 뉴스 헤드라인 숫자를 그대로 씀 |
| **SAM** (Serviceable Available Market) | 우리 제품·채널·지역으로 닿을 수 있는 범위는? | TAM에서 임의 비율(예: 10%)만 곱함 |
| **SOM** (Serviceable Obtainable Market) | 실제로 1~3년 안에 딸 수 있는 몫은? | 경쟁·영업역량을 빼놓고 낙관 |
| **Segment Map** | 그 안에서 **누가 돈을 내는가**? | 시장을 쪼개지 않고 뭉뚱그림 |

> 규모가 큰 것보다 **누가 실제로 돈을 낼 것인가**가 먼저입니다. TAM이 커도 지불 주체가 불분명하면 SOM은 0에 수렴합니다.
