## 대화 캡처 PDF

원본 ChatGPT 대화 캡처(`screencapture-chatgpt-*.pdf`, 72쪽)는 저장소 루트에 있으며 **`.gitignore`로 제외**되어 있습니다.

- 개인 리서치 대화 기록이고, 이 저장소가 **퍼블릭**이기 때문입니다
- 파일 크기도 7MB로 큽니다

공개해도 무방하다면 `.gitignore`에서 해당 줄을 지우고 이 폴더로 옮기면 됩니다.

## 두 리서치의 관계

| | 다루는 것 | 시장 규모 산정에서의 역할 |
|---|---|---|
| 01 자산군별 고객수요 | **누가 평가를 필요로 하는가** | 세그먼트 맵의 원재료 |
